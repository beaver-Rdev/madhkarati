# مذاكرتي — التهيئة

```bash
flutter create --org com.madhkarati --project-name madhkarati --platforms=android,ios,web,windows,macos,linux .
flutter pub get
flutter run -d chrome        # أو: flutter run
git init && git add . && git commit -m "init"
gh repo create madhkarati --private --source=. --push
```
فعّل GitHub Pages: Settings → Pages → Source: GitHub Actions.
